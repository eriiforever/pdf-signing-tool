# 盖章规则与示例参数

## 规则

1. 章 PDF 是**整幅图幅大小的透明图层**；整幅 1:1 叠加，绝不裁剪、缩放、旋转。
2. 图层右下角对齐页面右下角：`tx = 页面宽 - 图层宽`、`ty = 页面高 - 图层高`（再叠加 mediabox 原点偏移），逐页读取 `page.rect` / `mediabox`，不写死坐标。
3. 盖章前原件不动；覆盖模式下先备份到 `_未盖章原件\`，已存在不覆盖。盖完逐页校验，返工先恢复再重盖，绝不叠第二层。

## 示例章图层参数（示意章，非真实章）

| 项 | 值 |
|---|---|
| 图层幅面 | 1689.12 × 1195.92 pt（A2） |
| 章在图层内的框 | 约 205.92 × 79.20 pt |
| 距图层右边缘 | 约 49.92 pt |
| 距图层下边缘 | 约 599.76 pt |

整幅右下角对齐后，无论页面是 A2、加宽还是加高，章距页面右边缘恒约 50 pt；加宽 / 加高页面只是整体右移 / 下移。低 dpi 彩色检测有 ±3 pt 量化误差，判断异常看「某页比其它页大几十 pt」，不是 3 pt 抖动。

## 页码

- `all` 每页都盖（出图章场景）
- `first` 仅首页（公章场景）
- 自定义：`1,3,5` 或 `2-4`（用户输入 1 基页码）

## 输出与校验

- `stamped`：源文件目录\已签章\（默认，原件不动）
- `overwrite`：覆盖原文件，先备份
- `custom`：自定义目录

同名文件策略：`overwrite` 直接覆盖（默认）、`ask` 开始前一次性询问、`rename` 自动加后缀。

轻量校验：页数一致 + 每个盖章页的内容流确实引用了章图层新增的 XObject；更严格的视觉校验可自行渲染检测章位彩色墨迹占比。
