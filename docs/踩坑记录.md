# 踩坑记录

- **整幅图层 vs 裁下来的章**：把章抠出来贴页面角，在加宽图纸上会明显偏位。必须整幅图层右下角对齐。
- **pypdf 6.x**：`PdfReader` 没有 `__len__`，页数用 `len(doc.pages)`。
- **输出体积**：pypdf 重写页面会丢内容流 Flate 压缩，6 MB 图纸可能变 26~32 MB。做法是全篇共用同一个章对象，并对每页调用 `compress_content_streams()`。
- **透明度**：示意章用图像 XObject + `/SMask` 表达透明，不能把 RGBA 直接存成不透明 PDF，否则白色背景会盖住图纸。
- **Windows 控制台中文**：某些环境注入 `PYTHONUTF8=1` / `PYTHONIOENCODING=utf-8`，与 cp936 控制台冲突，bat 启动器里要显式覆盖编码。
- **bat 语法**：`if (...)` 块内的 `echo` 文本含括号会提前结束块。
- **Win32 文件框层级**：浏览器界面版里用 ctypes 弹文件框，窗口层级容易出问题；改用原生窗口框架的模态对话框后消失。
- **页码格式校验**：不要用只有 1 页的文档去校验页码范围，合法页码会被判越界。
- **dpi 参数**：渲染预览时 dpi 必须是 int，float 会触发底层类型错误。
- **盖章检测范围**：判断某页是否已盖章，只在预计章位的小矩形内统计彩色墨迹，整页检测会被图纸红字误判。
- **导入文件夹**：单页整幅透明章图层要自动归到章列表，否则会把章当成目标盖到自己身上（Windows 上会报文件占用错误）。
- **PyInstaller + PyMuPDF**（历史版本）：缺资源时抛 `FileNotFoundError` 而不是 `ImportError`，打包后启动崩溃；用 `--exclude-module pymupdf.layout` 规避。v2.0 起改用 pypdf，已无此问题。
