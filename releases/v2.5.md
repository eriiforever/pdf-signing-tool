# v2.5 · 当前版本

修一个定位 bug：**A1、A0 图幅的章落在了页面中部，没有贴右下角。**

## 问题

章图层是按整幅 A2 图幅做的，章画在图层右下角。定位时纵向用的是：

```
ty = 页面高 - 图层高
```

这个式子让**图层的右上角**对齐页面的右上角，章的位置是从纸顶往下量的。

A2 图纸高 1202，章图层高 1195.92，只差 6pt，所以看上去是贴底的，一直没人发现。换成 A1（页高 1684）就露馅了：章浮在距纸底 488pt 的位置，正好在页面中部偏下。

## 修复

纵向改成从纸底往上算：

```
ty = 页面底 - 图层底
```

图层的右下角真正对齐页面右下角。

实测九种图幅与旋转组合，章全部贴住右下角（距边 0–1px）：

| 图幅 | 页面 | 修复前距纸底 | 修复后 |
|---|---|---|---|
| A0 | 3370 × 2384 | 1188 pt | 0 |
| A1 | 2384 × 1684 | **488 pt** | 0 |
| A1 加长 | 2117 × 1202 | 6 pt | 0 |
| A2 | 1695 × 1202 | 6 pt | 0 |
| A3 | 1190.55 × 841.89 | 0 | 0 |
| A4 | 595 × 841 | 0 | 0 |
| A4 横 | 841 × 595 | 0 | 0 |
| A1 转 90 | 1684 × 2384 | — | 0 |
| A3 转 270 | 842 × 1191 | — | 0 |

## 需要留意的一处位移

A2 会向下移动 **6pt（约 2.1mm）**。

原因是章图层（1689.12 × 1195.92）比 A2 纸面（1695 × 1202）小一圈，旧公式让图层顶边对齐纸顶，底部自然空出 6pt；现在改成对齐纸底。

如果你之前盖的 A2 图纸要和新版本保持完全一致，可以在界面右下角把 `dy` 设成 `6`，补偿这一个差值。

从图纸里提取出来的章不受影响：提取时图层尺寸按原页生成，图层和页面一样大，新旧公式算出来完全相同。
