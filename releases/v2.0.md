# v2.0 · 独立窗口

第一个不依赖浏览器、可独立运行的版本。

- 窗口改为 tkinter 原生窗口，文件选择用系统原生对话框，关闭窗口即结束进程，后台无残留。
- PDF 叠加从 PyMuPDF 换成纯 Python `pypdf`，去掉 Qt / PySide6 依赖。
- 打包为单文件 exe，无黑框，目标机器无需安装 Python 或任何第三方库。
- 默认输出改为「源文件目录\已签章\」，原件不动；另可覆盖原件（自动备份）或自定义目录。
- 保留每页 / 仅首页 / 自定义页码、混合图幅逐页定位、备份不覆盖、逐页结构校验。

**源码留存情况**：该版本源码在同一文件上持续迭代，未单独留档；功能差异见 `CHANGELOG.md`。当前 `src/` 为 v2.1。

- 本 Release 附带 `PDFStamp-v2.0.exe`：按 v2.0 功能范围重建（只扫 `seals\`、同名自动加后缀、无完成后打开文件夹），**非当年留存的历史二进制**，仅用于演示该版本形态。
