# v3.0 · 当前版本

一次比较大的功能补齐，重点解决「盖错了要返工」和「重复盖叠层」两个痛点。

- **盖章前预览**：选中文件点「预览首页」，直接看首页叠章效果后再盖（内置渲染引擎，不用另装东西）。
- **已盖章检测（可选）**：勾选后跳过已经带这枚章的页，批量中止后重跑不会在已盖页上叠第二层；默认关闭。
- **章位微调**：dx / dy 输入框（±100 pt，步进 0.5），命令行 `--dx/--dy`；微调值会记住。
- **配置记忆**：章选择、页码策略、输出方式、同名策略、微调值写入程序旁的 `stamp_config.json`；换章自动套用这枚章上次用的页码策略。
- **盖章报告（可选）**：勾选后在输出目录生成 `盖章报告_时间.txt`，含文件、页数、盖章页、跳过页、大小、耗时，方便交付留痕与返工对照；默认关闭。
- 日志可另存为；启动时静默检查新版本（可关）。
- 工程化：新增 `tests/` 回归测试与 GitHub Actions，Release 附 `checksums.txt`。

**获取可执行文件**：本 Release 附带 `PDFStamp-v3.0.exe`（约 23 MB，内置预览渲染引擎），双击即用。
