# v2.1 · 稳定版

- 章候选自动发现：`seals\`、程序目录、当前目录、已添加图纸所在目录中带「章 / seal / stamp」的 PDF；启动、添加图纸、点开下拉、点「刷新」时重扫。
- 同名文件三策略：直接覆盖（默认）/ 提醒我 / 自动加后缀；命令行 `--exists`。
- 盖章完成后询问是否打开输出文件夹。
- 窗口尺寸按屏幕自适应，日志区为带双向滚动条的弹性面板。
- 内置示例章改为纯示意章：A2 整幅透明图层，右侧红框内写「测试章 / SAMPLE - NOT A REAL SEAL」，不含任何真实单位、编号或印章图案。可用 `tools/make_sample_seal.py` 复现。
- 输出体积优化：共用章对象 + 每页内容流重压缩。

**获取可执行文件**：v2.1 Release 附带 `PDFStamp-v2.1.exe`，双击即用；也可按 `tools/build_exe.md` 自行打包。

- 程序内显示 v2.1：窗口标题、界面标题旁、启动日志、命令行 `--version`；exe 右键属性→详细信息可见 FileVersion 2.1.0.0 / ProductVersion 2.1。

- 修复：批量盖章完成后窗口无法关闭（完成事件元组解包不一致，导致界面轮询停摆、`busy` 未复位）；轮询增加异常兜底，关闭窗口时提供强制退出选项。
