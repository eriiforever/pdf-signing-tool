# v2.2 · 当前版本

- **窗口内直接拖放**：把 PDF 或整个文件夹从资源管理器拖进程序窗口，自动加入待盖章列表；用 Windows 原生 `WM_DROPFILES` 实现，纯标准库、零新增依赖。
- 拖入文件夹时自动展开其中的 PDF；加文件后依旧会重扫同目录中带「章」字的章图层。
- 继承 v2.1 全部能力：同目录章自动发现、同名文件三策略、完成后打开输出文件夹、日志区弹性布局、内置脱敏示意章。
- 版本号 v2.2 写入窗口标题、界面、启动日志、`--version` 与 Windows 文件属性（FileVersion 2.2.0.0 / ProductVersion 2.2）。

**获取可执行文件**：本 Release 附带 `PDFStamp-v2.2.exe`，双击即用。
