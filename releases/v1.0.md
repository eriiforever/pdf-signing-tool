# v1.0 · 网页版（历史版本）

首个带图形界面的版本。

- 架构：Python 标准库 `http.server` 提供本地页面，内嵌 HTML 作为界面；不联网。
- 文件选择：直调 Win32 原生对话框（ctypes）。
- 功能：多枚章切换、导入文件夹自动分离章与图纸、每页 / 仅首页 / 指定页码、锚点微调、自动备份、跳过已盖章页、另存目录、预览、进度日志、从备份恢复。
- 分发：单文件 exe，目标机器无需 Python。
- 已知问题：文件对话框偶尔要切到任务栏才可见；输出目录只能是固定规则；关闭页面后进程靠心跳超时退出，用户不易判断是否已结束。

**源码留存情况**：该版本源码随后被整体改写，未单独归档，本仓库只保留架构与已知问题说明；历史二进制见本 Release 附件。

- 本 Release 附带 `PDFStamp-v1.0.exe`（网页版历史二进制，约 53 MB，双击后自动打开本地页面）。该二进制已逐模块扫描，未发现任何真实单位、项目或印章信息。
